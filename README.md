# Cybersecurity Home Lab

## Sobre o projeto

Este repositório documenta minha jornada de aprendizado em Cybersecurity por meio de laboratórios práticos realizados em ambiente controlado.

O objetivo é desenvolver conhecimentos em:

- Redes de computadores
- Linux
- Pentest
- Enumeração
- Análise de vulnerabilidades
- Documentação técnica
- Automação com Python

## Ambiente

- Windows (Host)
- VirtualBox
- Kali Linux
- Metasploitable 2
